# User Stories — R00001 Instanz starten

Rollen: **Betreiber** (startet die Instanz auf seinem Rechner, Vision „Nutzer und Nutzen“) und **Agent auf einem anderen Rechner im LAN**. Für jedes Szenario gilt: `<p>` ist der Port aus der Startzeile; Testordner werden nicht wiederverwendet.

## F0001 Starten mit Adresse

Als Betreiber möchte ich mit `localchatA <ordner>` eine Instanz starten und ihre Adresse ablesen, damit ich und die Agenten im LAN sie ansprechen können.

### US-1: Start auf freiem Port mit neuem Ordner

- **Gegeben** der Ordner `/tmp/lc-us1` existiert nicht
- **Wenn** der Betreiber `localchatA /tmp/lc-us1 --port 0 --host 127.0.0.1 --kein-browser` aufruft
- **Dann** existiert `/tmp/lc-us1`
- **Und** stdout zeigt genau `localchatA läuft für /tmp/lc-us1 unter http://127.0.0.1:<p>/` mit `<p>` ≠ 0
- **Und** `curl -s http://127.0.0.1:<p>/api/gesundheit` liefert 200 mit `"status":"bereit"`, `"ordner":"/tmp/lc-us1"` und `"nachrichten":0`

### US-2: Standard-Port weicht aus und ist im LAN erreichbar

- **Gegeben** auf Port 7430 lauscht bereits ein anderer Dienst (z. B. `python3 -m http.server 7430`), 7431 ist frei
- **Wenn** der Betreiber `localchatA /tmp/lc-us2 --kein-browser` aufruft
- **Dann** nennt die Startzeile `http://0.0.0.0:7431/`
- **Und** ein Agent, der `http://<LAN-Adresse des Rechners>:7431/api/gesundheit` aufruft (z. B. `192.168.1.20`), erhält 200 mit `"status":"bereit"`

### US-3: Geordnetes Ende

- **Gegeben** eine Instanz läuft nach US-1 auf `/tmp/lc-us1`
- **Wenn** der Betreiber im Terminal Strg+C drückt
- **Dann** endet das Programm mit Exit-Code 0 (`echo $?` → `0`)
- **Und** `curl http://127.0.0.1:<p>/api/gesundheit` erhält keine Verbindung mehr

### US-4: Falscher Aufruf und Hilfe

- **Gegeben** keine Instanz läuft
- **Wenn** der Betreiber `localchatA --gibtsnicht` aufruft
- **Dann** endet das Programm mit Exit-Code 2, und stderr nennt `--gibtsnicht` und verweist auf `--hilfe`
- **Und** `localchatA --hilfe` zeigt die Aufrufzeile mit `--port`, `--host`, `--kein-browser` und endet mit Exit-Code 0

### US-5: Ordner nicht anlegbar

- **Gegeben** `/tmp/lc-datei` ist eine gewöhnliche Datei (`touch /tmp/lc-datei`)
- **Wenn** der Betreiber `localchatA /tmp/lc-datei/unter --port 0 --kein-browser` aufruft
- **Dann** endet das Programm mit Exit-Code 1, und eine Zeile auf stderr nennt `/tmp/lc-datei/unter`

## F0002 Ordner gegen zweite Instanz sperren

Als Betreiber möchte ich, dass auf einem Ordner nur eine Instanz läuft, damit nie zwei Programme denselben Verlauf schreiben.

### US-6: Zweiter Start wird abgewiesen

- **Gegeben** eine Instanz läuft auf `/tmp/lc-us6` (gestartet mit `--port 0 --kein-browser`)
- **Wenn** der Betreiber in einem zweiten Terminal `localchatA /tmp/lc-us6 --port 0 --kein-browser` aufruft
- **Dann** endet der zweite Aufruf mit Exit-Code 1, und stderr nennt `/tmp/lc-us6` und dass der Ordner bereits von einer Instanz gesperrt ist
- **Und** die erste Instanz antwortet weiter mit 200 auf `/api/gesundheit`

### US-7: Neustart nach dem Ende

- **Gegeben** die erste Instanz aus US-6 wurde mit Strg+C beendet, `/tmp/lc-us6/.localchatA.sperre` liegt noch im Ordner
- **Wenn** der Betreiber erneut `localchatA /tmp/lc-us6 --port 0 --kein-browser` aufruft
- **Dann** erscheint die Startzeile, und `/api/gesundheit` antwortet 200

## F0003 Oberfläche ausliefern

Als Betreiber möchte ich nach dem Start die Oberfläche im Browser sehen, damit ich weiß, dass Weboberfläche und API aus demselben Programm kommen.

### US-8: Browser öffnet die Oberfläche

- **Gegeben** eine grafische Sitzung mit Standardbrowser
- **Wenn** der Betreiber `localchatA /tmp/lc-us8 --port 0` aufruft (ohne `--kein-browser`)
- **Dann** öffnet sich der Standardbrowser mit `http://127.0.0.1:<p>/`
- **Und** der Tab trägt den Titel `localchatA`, und die Browser-Konsole zeigt keine Fehler

### US-9: Ohne Browser

- **Gegeben** eine Instanz wird mit `--kein-browser` gestartet
- **Wenn** die Startzeile erscheint
- **Dann** öffnet sich kein Browser
- **Und** `curl -si http://127.0.0.1:<p>/` liefert 200, `Content-Type: text/html`, `Cache-Control: no-cache` und `<title>localchatA</title>`

### US-10: Unbekannte Datei

- **Gegeben** eine Instanz läuft
- **Wenn** jemand `http://127.0.0.1:<p>/web/gibtsnicht.js` aufruft
- **Dann** antwortet das Programm mit 404
