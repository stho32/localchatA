# Umgebung

Wie die Dienste des Projekts starten und geprüft werden. Gilt für den Director und jede Rolle.

| Was | Befehl / Wert |
|---|---|
| Abhängigkeiten installieren | rustup stable ≥ 1.89 (Edition 2024, clippy, rustfmt); Node.js mit npm; einmalig `npm --prefix e2e ci` und `npx --prefix e2e playwright install chromium` (ADR-0001, ADR-0009); `ffmpeg` und `ffprobe` für die Tilger-Integrationstests (`tests/anhaenge_traeger.rs`, `tests/anhaenge_arten.rs` — fehlen sie, ist der Test rot „Vorbedingung fehlt“); `exiftool` optional nur für Reviewer-Proben, nicht im Gate (hier nicht installiert) |
| Dienste starten (freier Port) | `cargo run -- <ordner> --port 0 --host 127.0.0.1 --kein-browser`; Adresse aus der Startzeile `localchatA läuft für <ordner> unter http://…/`; Standard ohne Angaben 0.0.0.0:7430 mit Ausweichen; nie 7420 oder 7421 (kanbanD) |
| Health-Check | `curl -fs <adresse>api/gesundheit` → 200 `{"status":"bereit",…}` |
| Gate (alle Tests, Analyse) | `cargo fmt --all -- --check` · `cargo clippy --all-targets --all-features -- -D warnings` · `cargo test` · `npm --prefix e2e test` (erst `node --test einheit/` für die Oberfläche, dann Playwright; baut das Programm selbst) |
| Lastprofil „Team-LAN“ (Betreiber 2026-10-28) | gleichzeitig bis 20 Menschen und 50 Agenten; Spitze 30 Nachrichten/s gesamt, dauerhaft 5/s; bis 100.000 Nachrichten je Channel, 50 Channels aktiv; Zustellung live < 1 s, Channel öffnen < 500 ms, Suche < 1 s; Server ist ein normaler Rechner im LAN. Maßstab für Grenzen gegen Flut und Leistungskriterien; als Leitplanke in der Vision (2026-10-28) |
| Logging-Konzept (Betreiber 2026-10-28) | Betriebsprotokoll als Datei im Instanzordner unter `logs/`, täglich rotierend, Aufbewahrung 14 Tage, danach bereinigt; Stufen Debug · Information · Warning · Error (Fachlogik) · Exception (Programmfehler), Standard Information, Debug zuschaltbar; Details entscheidet der architekt (ADR), geprüft vom observability-reviewer. Gebaut mit I0021 (#24): Datei `<ordner>/logs/JJJJ-MM-TT.log` (lokales Datum), ab WARNING gespiegelt auf stderr; Stufe `--protokoll-stufe` bzw. `LOCALCHATA_PROTOKOLL_STUFE=debug\|information\|warning\|error` (Option geht vor, falscher Wert Exit 2); Testknöpfe `LOCALCHATA_TESTPANIK=verlauf\|takt\|loeschen` (nur Debug-Build, anderer Wert Exit 2, im Release nicht gelesen) und `LOCALCHATA_EPISODE_RUHE_MS` (Standard 60000; 0, leer, keine Zahl Exit 2) |
| Demo (Betreiber) | `http://127.0.0.1:7431/`, Ordner `/home/shoff/Projekte/localchatA-demo/daten`, über `~/.cargo/bin/localchatA` (cargo install); aktualisiert nur der Director mit `/home/shoff/Projekte/localchatA-demo/demo-aktualisieren.sh` nach jedem Zug in die Abnahme und auf Wunsch — Rollen fassen Port 7431 und den Demo-Ordner nie an, auch nicht zum Testen |
| SDKs / Pfade | `~/.cargo/bin`; kanbanD-Board `http://127.0.0.1:7421`, Ordner `/home/shoff/Projekte/localchatA-kanbanD`; Tests nur mit `--port 0`, Wegwerf-Ordner, Einstellungen über `LOCALCHATA_*` (Testuhr `LOCALCHATA_JETZT=<RFC 3339>`, Zeitzone in Tests `TZ=Europe/Berlin`, Gnadenfrist `LOCALCHATA_GNADENFRIST_MS` ab I0004, Herzschlag des Ereignisstroms `LOCALCHATA_HERZSCHLAG_MS` ab I0005, Standard 5000 ab I0006, im E2E nie über 5000 wegen des Wächters von 15 s — 0 ist Fehler, Exit 2); zusätzliche Hostnamen für den Grenzschutz mit `--erreichbar-als <name>` (ADR-0014); Prozessende bei hängender Namensauflösung (B0485, L2r): `cargo test --test prozessende -- --ignored` — braucht nss-mdns (`hosts: … mdns4_minimal …`, avahi läuft), fehlt es, ist der Test rot „Vorbedingung fehlt: nss-mdns“, ≈ 6 s, im Entwicklertest ausdrücklich fahren, nicht im Standard-Gate; Health `anhaenge_ungekuerzt` (gelöschte, noch nicht gekürzte Anhänge, ab #73); Plattenquote `--plattenquote <größe>` bzw. `LOCALCHATA_PLATTENQUOTE=<n>MiB|<n>GiB|aus` (Standard 4GiB, 1 MiB bis 1.024 GiB, falsch Exit 2; Health `plattenquote`, `quote_abgewiesen`; Testhelfer `target/debug/examples/quote-ordner <ordner> <channel> <bytes>`); Namen des eigenen Netzes (Rückwärtsname, lokaler Namensraum) gelten automatisch, `--alle-namen` bzw. `LOCALCHATA_ALLE_NAMEN=1` nimmt jeden Namen (ADR-0045); Testknopf `LOCALCHATA_TESTNAMEN=<name>=<ip>[,<ip>];<ip>><name>` ersetzt die Namensauflösung (nur Debug-Build, falsch Exit 2, im Release nicht gelesen); der LAN-Test braucht eine Nicht-Loopback-IPv4 mit Default-Route |
