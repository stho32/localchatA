# ScreenFlow

Alle Bildschirme aus dem Auftrag und ihre Übergänge; Dialoge und Overlays gehen von der Hauptansicht aus und kehren dorthin zurück.

- Gestrichelt: automatische Übergänge (gemerkter Name, Rücksprung aus Suche und Erwähnungen).
- Rot gestrichelt: Zustände des Beitreten-Bildschirms, keine eigenen Seiten.
- Die Direktnachricht ist kein eigener Bildschirm, sondern die Hauptansicht im Privat-Modus.
