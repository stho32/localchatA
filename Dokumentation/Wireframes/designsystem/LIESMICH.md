# localchatA — Designsystem (Export)

- `README.md` — Gestaltungsgrundsätze; `1-tastatur.md`, `2-token-erweiterung.md`, `3-offene-fragen.md` — weitere Abschnitte
- `tokens.json` — alle Tokens (Quelle); `tokens.css` — daraus erzeugte CSS-Variablen (Hell/Dunkel über `data-theme="light|dark"`)
- `components/bundle.css` — Grundformen; `components/<Name>/README.md` — Regeln je Baustein; `preview.html` — Vorschau, wie sie im Artifact läuft
- `vorschau/<Name>.html` — dieselben Vorschauen, direkt im Browser zu öffnen (Dunkelmodus: `data-theme="dark"` am `<html>` setzen)
- `bilder/` — Renderings aller Vorschauen in Hell und Dunkel
- `design-system.json` — Index des Artifacts
